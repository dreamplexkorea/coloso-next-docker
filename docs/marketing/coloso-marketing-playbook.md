# Coloso 마케팅 플레이북 (프로페셔널 · 포터블)

> **이 문서의 목적**: 클로소(coloso.co.kr)의 실제 랜딩/상세페이지를 종합 분석해 추출한 **전환 중심 마케팅 자산**을, 임의의 프로그램·제품·프로젝트에 그대로 이식할 수 있도록 정리한 실전 플레이북.
> **포터빌리티**: 본문은 ① 범용 원리 → ② 빈칸형 템플릿 → ③ 진로직업체험 도메인 적용 → ④ 다른 도메인 일반화 순으로 구성. 다른 레포에 복사해도 동작하도록 외부 의존 없이 작성.
> **근거**: 실제 캡처 8종(일러스트 `illustrator-rojo4`, 베이킹 `patissier-choijihye`, 3D `3ddesign-hiro`, 그래픽/레터링 `graphicdesign-futuredrops`, 헤어 `hairdesigner-jini`, 게임기획 `gamedesigner-maiz`, AI영상 `ai-yeeuone`, 무료퍼널 `snack-business-shininhwa-free`) + 홈/카테고리. 인용 카피는 캡처 원문.

## 0. 한 장 요약 (TL;DR)

클로소 상세페이지는 **"전문가 권위 → 구체적 성과 약속 → 마찰 제거 → 시간 기반 긴급성"** 4축으로 전환을 만든다.
- 가격은 거의 균일(₩251k~276k)하고 **할인보다 "얼리버드 + 무이자 할부 + 평생시청"** 으로 마찰을 없앤다.
- 긴급성은 재고가 아니라 **콘텐츠 오픈일**(`영상오픈 07.30(목) 18시`)로 만든다.
- 신뢰는 **구체 수치 + 실명 브랜드 협업**(배민·케이뱅크·Netflix·진격의 거인·"170만 뷰"·"누적 수강생 1만+")으로 만든다.
- 모든 페이지가 **문제 제기 → 체계적 해법("감각을 논리로") → 산출물 → 사회적 증거 → 듀얼 CTA**의 같은 골격.

## 1. 설득 프레임워크 카탈로그 (9 + α)

각 기법: **정의 / 발동 조건 / 클로소 실제 예 / 빈칸 템플릿 / 안티패턴.**

### 1.1 성과·수치 프레이밍 (Outcome & Number Framing)
- **정의**: 추상적 효익이 아니라 **구체적 결과물 + 숫자**로 약속.
- **발동**: 히어로 헤드라인, 가치제안.
- **클로소 예**: "하루 100조각 생산, 1인 케이크샵의 고효율 레시피 17종" / "3천 자 이상의 폰트 제작 경험" / "단 1시간 만에 손상 없이 완벽한 결 개선".
- **템플릿**: `[구체 수치/기간] 만에 [측정 가능한 결과]를 만드는 [대상]용 [무엇]`.
- **안티패턴**: "최고의 강의", "쉽게 배우는" 같은 형용사 남발.

### 1.2 문제-자극-해결 (PAS: Problem–Agitate–Solve)
- **정의**: 타깃의 페인을 먼저 호명·자극한 뒤 해법 제시.
- **클로소 예**: "녹고 탄 손상모, 악성곱슬 고객은 막막하기만 하셨나요? 눈대중에 의존하던 펌 시술은 이제 그만!" / "폰트를 바꿔도 결과물이 늘 비슷하고 평범" / "막연한 감으로 쓰는 글쓰기는 그만".
- **템플릿**: `[타깃이 매일 겪는 구체적 실패]로 막막하셨나요? [기존 방식]은 이제 그만 — [체계]로 해결합니다.`
- **안티패턴**: 페인 없이 기능부터 나열.

### 1.3 체계화 차별점 ("감각을 논리로")
- **정의**: 경쟁(취미/직관)과 차별화해 **"체계·프레임워크"** 로 포지셔닝.
- **클로소 예**: "감각을 '논리'로!" / "논리로 배우는" / "비례 시스템, 구조 설계, 시각 보정 기반" / 게임시나리오를 "창작 글쓰기가 아니라 구현 가능한 시스템 설계로".
- **템플릿**: `[직관/감]에 의존하던 [분야]를 [원리/시스템/판단기준]으로 바꿉니다.`

### 1.4 권위·전문가 신뢰 (Authority)
- **정의**: 강사의 경력·직함·출간·수상·현직성으로 신뢰 구축.
- **클로소 예**: "20년+ 경력, 진격의 거인·Netflix 참여" / "배달의민족·케이뱅크 협업 디자이너" / "국내외 2천 회 이상 세미나, JINI ACADEMY 운영" / "NDC·IGC·KGC 강연, 저서 2권".
- **템플릿**: `[연차]년 [분야] + [대표 실적/브랜드] + [출간/강연/수상]`.
- **주의**: 검증 가능한 고유명사만. 막연한 "업계 최고" 금지.

### 1.5 사회적 증거 (Social Proof — 지표·후기·동료추천)
- **정의**: 숫자 지표 + 실명 후기 + 동료/권위자 추천.
- **클로소 예**: "누적 수강생 1만+" / "170만 뷰" / "다수의 합격 후기로 증명"(Webzen·NineArc 등 재직자 후기) / 동료 일러스트레이터 추천 / 비포-애프터 갤러리.
- **3종 세트**: ① 정량 지표 ② 실명/소속 후기 ③ 시각적 비포-애프터.

### 1.6 산출물 앵커링 (Deliverable Anchoring)
- **정의**: "무엇을 받고 무엇을 완성하는가"를 구체 목록화해 가치를 고정.
- **클로소 예**: "41회차 강의 무한 학습 / 캐릭터 모델링 1종 완성 / 베이스 3D 모델 제공" / "원본 일러스트 파일" / "스케치 5종 + 완성 9종 파일".
- **템플릿**: 체크리스트 3~5개 — `[N회차 콘텐츠]` · `[완성 결과물 1종]` · `[제공 자료/템플릿]`.

### 1.7 가격 앵커 + 마찰 제거 (Price Anchor & Friction Reduction)
- **정의**: 표시가를 앵커로 두되, **할인보다 결제 마찰 제거**로 구매장벽을 낮춤.
- **클로소 예**: 거의 모든 강의 ₩251k~276k 균일, "12개월 무이자 할부", "평생시청"(만료 불안 제거), 상세 환불정책.
- **레버**: 무이자 할부 · 평생 접근 · 자료 포함 · 투명 환불.

### 1.8 시간 기반 긴급성 + 보너스 (Deadline Urgency)
- **정의**: 재고가 아니라 **콘텐츠 오픈일/얼리버드 마감**으로 긴급성 생성, 선결제 보너스로 가속.
- **클로소 예**: "영상오픈 07.30(목) 18시" / "얼리버드 구매자 대상 10명 추첨 1:1 Q&A" / "최종 강의 공개일 이전 결제자에게 보너스 레시피" / "클래스 오픈 특전".
- **템플릿**: `[오픈일시] 공개 — 그 전 신청자에게만 [보너스/특전]`.
- **윤리 주의**: 허위 마감 금지. 실제 일정과 일치시킬 것.

### 1.9 듀얼 CTA (Commitment Ladder)
- **정의**: 고관여(구매)와 저관여(예약/무료)를 동시에 제공해 이탈을 흡수.
- **클로소 예**: 1차 "얼리버드 구매하기" + 2차 "수강예약" / "크리에이터페이지 바로가기".
- **원리**: 지금 안 사는 사람도 **예약/팔로우**로 리드화.

### 1.10 무료 퍼널 (Lead-Gen Funnel) — `[0원]` 스낵 강의
- **정의**: 무료/초저가 콘텐츠로 신뢰·리드 확보 후 유료 전환.
- **클로소 예**: "[0원] 재계약을 부르는 백화점 팝업…", "어디서도 배울 수 없는 풀 프로세스 대공개!", 수강에 **계정+이메일 등록** 요구(리드 캡처) → 인접 유료강의 업셀.
- **구조**: 무료 후킹 → 가치 입증 → 리드 캡처 → 인접 유료 추천.

### 1.11 반론 처리 (Objection Handling) — Q&A 인터뷰 + 환불
- **정의**: 예상 반론을 강사 Q&A와 투명 약관으로 선제 해소.
- **클로소 예**: "이론인가 실전인가? → 현실 베이킹" / "전작과 뭐가 다른가? → 완성 로직" / 프리퀴지트 명확화 / 단계별 환불 스케줄.

## 2. 카피 공식 + 템플릿 (복붙용)

> 전체 복붙용 템플릿(랜딩 13단 스켈레톤·채널 자산·배지/CTA 라이브러리·워크드 예시·타도메인 이식)은 **`coloso-copy-templates.md`** 참조.

### 2.1 히어로 3종 세트
```
EYEBROW(감성 후킹·1줄):   "[타깃의 욕망/상황을 건드리는 한 구절]"
HEADLINE(성과형·굵게):     "[구체 수치/결과] + [핵심 무엇] + [전문가/방식]"
SUBCOPY(증명·해법):        "[실명 브랜드/경력]의 [무엇]으로 [페인]을 해결합니다."
```
실제 예(레터링): EYEBROW "내 손으로 설계하는 차별화된 한글&영문 레터링" / HEADLINE "타이포그래피/레터링 디자인 실무…포트폴리오 완성하기" / SUBCOPY "배달의민족, 케이뱅크 협업 디자이너 퓨처드롭스의 레터링 클래스 하나로 해결!"

### 2.2 배지 카피 패턴
| 목적 | 카피 예 |
|------|---------|
| 신규 | `NEW` · `신규 오픈` |
| 추천 | `강력추천` · `BEST` |
| 긴급 | `마감임박` · `얼리버드` · `08.06 오픈` |
| 한정 | `OOO에서만` · `한정 특전` |
| 상태 | `수강가능` · `예약중` |

### 2.3 듀얼 CTA
```
PRIMARY:   "얼리버드 구매하기" / "지금 신청하기"
SECONDARY: "수강예약" / "상담 신청" / "크리에이터/프로그램 페이지 바로가기"
```

### 2.4 증빙지표(Proof Stat) 3칸 공식
```
[지표1: 규모]   예) 운영 학교 122+ / 누적 수강생 1만+
[지표2: 참여]   예) 참여 학생 6,883+ / 170만 뷰
[지표3: 품질]   예) 평균 만족도 4.8/5.0 / 재방문율 60%+
```

---

## 3. 증빙지표 설계법 (Proof Architecture)

1. **수집 우선순위**: 규모(누적) → 참여(반복) → 품질(만족/추천) → 성과(전환/취업).
2. **표현 규칙**: 반올림 + `+` 기호로 성장감("6,883+"), 소수점은 만족도에만(4.8/5.0).
3. **신뢰 강화**: 가능하면 출처/기간 부기. 실명 소속 후기 1~2개를 지표 옆에 배치.
4. **데이터 모델 매핑(본 레포)**: `HeroProofStat { label, value }` → `CourseDetail.heroProofStats`. 이미 `ai-programming.ts`에 "운영 학교 122+ / 참여 학생 6,883+ / 평균 만족도 4.8/5.0" 패턴 존재.

## 4. 오디언스 세그먼트 × 메시지 매트릭스

> 클로소가 "3~5년차 디자이너 / 1인샵 원장 / 주니어"를 분리 호명하듯, **구매자와 사용자가 다른 B2B2C** 구조에선 세그먼트 분리가 핵심.

| 세그먼트 | 핵심 동기 | 주요 반론 | 메시지 앵글 | 톤 |
|----------|-----------|-----------|-------------|----|
| **학교/교사**(의사결정·구매) | 운영 편의, 교육과정 부합, 안전, 만족도 | 준비 부담? 예산? 효과 입증? | "재료·강사 전원 방문, 학급 단위 무준비 운영 + 만족도 4.8" | 신뢰·간결·행정 친화 |
| **학부모**(영향자) | 자녀 진로 도움, 안전, 가성비 | 일회성 아닌가? 실질 도움? | "현직 전문가가 직접, 진로 탐색으로 연결되는 체험" | 따뜻·근거 |
| **학생**(사용자·경험) | 재미, 새로움, 또래 인증 | 지루할까? 어려울까? | "교과서 밖 진짜 세상, 직접 만들어보는" | 활기·체험 중심 |

**적용 규칙**: 히어로/공문은 **구매자(학교)** 톤, 후기/갤러리는 **학생** 톤, 기대효과 섹션은 **학부모** 톤으로 분배.

## 6. 전환 아키텍처 체크리스트 (랜딩 13단)

클로소 상세페이지 골격을 **전환 점검표**로. 새 프로그램 페이지를 만들 때 순서대로 체크:

1. ☐ **히어로**: 성과형 헤드라인 + 감성 eyebrow + 강사 정체성 + 증빙 1줄 + 듀얼 CTA
2. ☐ **문제/페인**: 타깃의 구체적 실패를 호명(PAS)
3. ☐ **가치제안**: 산출물 3~5개 체크리스트
4. ☐ **사회적 증거**: 지표 3칸 + 실명 후기 + 비포-애프터
5. ☐ **정보 박스**: 대상·차시·소요시간·방식·언어·자료포함
6. ☐ **커리큘럼**: 점층 구조 + 기술용어 + 성과 언어 혼합
7. ☐ **강사 권위**: 경력·실명 실적·출간·현직성
8. ☐ **Q&A 인터뷰**: 예상 반론 4개 선제 해소
9. ☐ **예시 갤러리**: 결과물 시각 증거
10. ☐ **(선택) 시리즈/연계**: 업셀·후속 과정
11. ☐ **신뢰/유의사항**: 투명 환불·운영 정책
12. ☐ **가격/결제**: 앵커 + 무이자 할부 + 평생/혜택
13. ☐ **최종 CTA**: 듀얼(고관여 + 저관여), 긴급성 재강조

## 8. 포터빌리티 — "임의의 프로그램/제품에 적용하는 5단계"

1. **타깃 정의**: 구매자/영향자/사용자를 분리(§4 매트릭스 채우기).
2. **앵글 선택**: §1에서 2~3개 프레임워크 선택(성과 프레이밍 + PAS + 권위 권장).
3. **증빙 수집**: §3 3칸(규모·참여·품질)을 실제 데이터로 채움.
4. **카피 생성**: §2 템플릿으로 히어로·배지·CTA·증빙 카피 작성, 세그먼트 톤 분배(§4).
5. **랜딩 조립 + 점검**: §6 13단 체크리스트로 페이지 구성·검수, §5 채널별 자산 파생.

> 이 5단계는 도메인 무관. 교육·체험·B2B SaaS·로컬 비즈니스 어디든 §1·§2·§3·§6만 가져가면 작동한다. 도메인 전용 표현만 §7처럼 매핑 테이블로 교체.

## 9. 윤리/품질 가드레일
- 허위 마감·허위 지표·과장 보증 금지. 모든 숫자·일정·약관은 **검증 가능·실제와 일치**.
- 권위는 **고유명사 + 검증 가능 실적**으로만. "업계 최고" 류 형용사 금지.
- 아동·학생 대상 카피는 안전·교육적 가치를 과장 없이. 공포 마케팅 지양.
- 접근성: 카피는 명료하게, 핵심 정보(대상·일정·신청법)는 텍스트로 제공.
