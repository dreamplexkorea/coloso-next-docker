# Coloso 카피 템플릿 팩 (포터블 · 복붙용)

> **목적**: `coloso-marketing-playbook.md`의 공식을 **빈칸만 채우면 되는 실전 템플릿**으로 제공. 도메인 무관 — 진로직업체험뿐 아니라 어떤 프로그램·제품·로컬 비즈니스에도 복사해 사용.
> **사용법**: `[대괄호]` = 채울 슬롯, `{선택}` = 택1, `// 주석` = 작성 지침. 채운 뒤 윤리 가드레일(플레이북 §9)로 검수.
> **연계**: 채운 결과는 `coloso-copywriter`가 데이터 필드(`heroHeadline` 등)에 반영, `coloso-ui-designer`가 13단 아키타입으로 배치.

---

## 0. 5분 퀵스타트 (플레이북 §8 압축)
1. **타깃** 3명 적기(구매자/영향자/사용자). 2. **앵글** 2~3개 고르기(성과·PAS·권위). 3. **증빙 3칸** 실데이터로 채우기. 4. 아래 §1 히어로부터 순서대로 빈칸 채우기. 5. §6 채널 자산 파생.

---

## 1. 히어로 3종 세트 템플릿
```
EYEBROW:   [타깃의 욕망/상황 한 구절]               // 예: "교과서 밖 진짜 세상을 만나는"
HEADLINE:  [구체 수치/기간] + [핵심 결과] + [방식/전문가]
           // 공식: "○○분/차시 만에 △△를 직접 만드는 □□ 체험"
SUBCOPY:   [실명 경력/기관]이 [방식]으로 [페인]을 해결합니다.
```
**배지**: `{NEW|강력추천|BEST}` · `{[MM.DD] 오픈|마감임박|얼리버드}` · `{[기관]에서만}`
**듀얼 CTA**: PRIMARY `[지금 신청하기|상담 신청]` / SECONDARY `[프로그램 자세히|샘플 보기]`

## 2. 증빙지표 3칸 워크시트
```
[지표1·규모]  라벨 "[운영 학교|누적 참여]"   값 "[N]+"     출처 "[___]"  // 미확보 시 // 운영자 확인 필요
[지표2·참여]  라벨 "[참여 학생|재참여율]"     값 "[N]+ | N%" 출처 "[___]"
[지표3·품질]  라벨 "[평균 만족도|추천율]"      값 "[N.N/5.0]"  출처 "[___]"
```

## 3. 랜딩 13단 카피 스켈레톤 (코어 9단 필수 · 레퍼런스 §2.6)
```
1  히어로        → §1 세트
2  문제/페인     "[타깃의 구체적 실패 장면] 때문에 막막하셨나요?"
3  가치제안(3카드) "① [산출물]  ② [제공 자료]  ③ [완성 결과 1종]"
4  사회적 증거    [증빙 3칸] + 후기 "[실명/소속] — '[한 줄 결과]'" + 비포애프터 [이미지]
5  정보 박스     대상 [___] · 차시 [___] · 소요 [___] · 방식 [___] · 자료 [포함] · {할부/예산 [___]}
6  커리큘럼      Ch1 [기초·원리] → Ch2 [실습·완성]   // 점층 + 성과 언어
7  강사 프로필    [연차]년 [분야] · [실명 실적/기관] · {출간/강연}
8  Q&A 인터뷰    Q1 신뢰 Q2 차별점 Q3 난이도/대상 Q4 메시지   // 반론 선제 해소
9  예시 갤러리    [활동/결과물 이미지·영상]
10 (선택)시리즈   "[N부작 중 현재 위치]"
11 유의/환불      [운영 안내] · [환불/취소 규정]
12 가격/결제      [표시가] {· 무이자 할부 | · 예산 안내 | · 0원}
13 듀얼 CTA       [PRIMARY] + [SECONDARY] + 긴급성 재강조
```

## 4. 배지 & CTA 라이브러리 (복붙)
| 상황 | 배지 | 1차 CTA | 2차 CTA |
|------|------|---------|---------|
| 신규 출시 | `신규 오픈` `NEW` | 지금 신청하기 | 프로그램 자세히 |
| 인기/추천 | `강력추천` `BEST` | 상담 신청 | 후기 보기 |
| 마감 임박 | `마감임박` `[MM.DD] 오픈` | 마감 전 신청 | 일정 문의 |
| 한정/독점 | `[기관]에서만` `한정 특전` | 특전 받고 신청 | 자세히 |

## 5. 채널 자산 템플릿 (플레이북 §5)

### 5-A. 학교 공문 1-pager
```
[프로그램명] — [한 줄 가치]
· 대상: [학년] / 차시: [N차시 N분] / 방식: [학교 방문형]
· 검증: [운영 학교 N+] · [참여 학생 N+] · [만족도 N.N/5.0]
· 운영: 재료·강사 전원 방문, 학급 단위 무준비 운영
· 신청/문의: [연락처 / 신청 링크]
```

### 5-B. SNS 숏폼 스크립트(15~30초)
```
HOOK(0-3s):  "[타깃] 주목! [의외의 결과] 직접 만들어봤어요"
BODY(3-20s): [활동 비포→애프터 컷] + "[핵심 성과 자막]"
CTA(20-30s): "[프로그램명] · 프로필 링크에서 상담 신청"
```

### 5-C. 블로그 케이스 스터디
```
제목: [학교/지역] [프로그램] 운영 후기 — [수치 성과]
1 배경(어떤 학교·니즈)  2 운영(차시·활동)  3 결과(만족도·후기 인용)  4 신청 안내(CTA)
```

### 5-D. 이메일/DM
```
제목: [학년] 진로체험, [핵심 혜택] 한 번에
본문: [페인 1문장] → [해법·증빙 2문장] → [CTA: 상담 신청 링크]  // 3문장 원칙
```

## 6. 워크드 예시 — "바리스타 직업체험" (템플릿 적용 결과)
> 데이터: `src/lib/data/courses.ts`의 `barista-experience`(초등·90분). 수치는 예시이며 실제 운영 데이터로 교체 필요(// 확인 필요).

**히어로**
- EYEBROW: "커피 향으로 만나는 첫 직업 체험"
- HEADLINE: "90분 만에 나만의 라떼아트를 완성하는 바리스타 직업체험"
- SUBCOPY: "현직 바리스타가 학교로 찾아가, 원두 향부터 라떼아트까지 직접 체험시킵니다."
- 배지: `강력추천` · `초등 인기`
- 증빙 3칸: 운영 학교 `80+` // 확인 필요 · 참여 학생 `3,200+` // 확인 필요 · 만족도 `4.7/5.0` // 확인 필요
- 듀얼 CTA: "상담 신청" / "프로그램 자세히"

**가치제안 3카드**: ① 원두 그라인딩~추출 직접 체험 ② 라떼아트 1종 완성 ③ 바리스타 직업 진로 워크북 제공
**정보 박스**: 대상 초등 전학년 · 90분(1차시) · 학교 방문형 · 재료 전량 제공
**기대효과(학부모 톤)**: "커피라는 친숙한 소재로 '직업 세계'를 처음 탐색하고, 손으로 만드는 성취감을 경험합니다."
**듀얼 CTA 카피**: PRIMARY "상담 신청" / SECONDARY "프로그램 자세히 보기"

→ 이 결과를 `coloso-copywriter`가 `heroHeadline`·`heroSubcopy`·`heroChips`·`heroProofStats`·`badges`에 반영, `coloso-ui-designer`가 `ProductHero`+13단으로 구현.

## 7. 다른 도메인으로 이식 (포터빌리티 증명)
같은 템플릿, 도메인만 교체:
- **로컬 베이커리 클래스**: HEADLINE "3시간 만에 홈베이킹 마스터하는 주말 클래스" / 증빙 "수강생 1,200+ · 재등록 45% · 만족도 4.8" / CTA "예약하기/메뉴 보기".
- **B2B SaaS 데모**: HEADLINE "2주 만에 리포팅 시간 70% 줄이는 대시보드" / 증빙 "도입 기업 320+ · 절감 시간 70% · NPS 62" / CTA "데모 신청/도입 사례".
> §1·§3·§4만 가져가면 어느 도메인이든 작동. 도메인 표현만 교체하라.
