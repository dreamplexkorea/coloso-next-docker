## 재설계에서 제안했지만 아직 운영 확정은 아닌 것

- 거인의 어깨를 첫 파일럿으로 사용한다.
- 원본 비교 환경은 1440×900·390×844를 우선하며 360px·768px도 확인한다.
- 프로그램별 2·4·6차시를 다른 목표·결과물의 운영안으로 관리한다.
- 기존 Next.js 공개 라우트는 유지하고 관리자·버전·발행을 추가한다.
- 개발 순서는 P0 → P1 → P2 → P3 → P4 → P5로 둔다.

이 결정이 바뀌면 이유·영향·관련 요구 ID를 기록한다. 미결 사항이 해소되면 원자료와 확인자·일시를 연결하고 완료 처리한다.
