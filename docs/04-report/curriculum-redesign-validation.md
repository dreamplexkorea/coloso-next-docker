# 재설계 검증 기록

2026-09-07 · 검증 대상: 이번 브랜치의 상세 수업 구조, 화면 연결 및 문서.

| 확인 항목 | 결과 | 의미 |
|---|---|---|
| `npm run build` | 통과 | 프로덕션 컴파일·TypeScript·페이지 생성 성공 |
| `npm run test:curriculum` | 5개 통과 | 수업 시간/필수 내용, 잘못된 구성, 운영 확정 검토 기록, 견적 전달 검증 |
| `npm run test:recently-viewed` | 기존 5개 통과 | 주소 정리와 함께 기존 최근 본 항목 처리 유지 확인 |
| `npm run lint` | 오류 0, 기존 경고 4 | 미사용 항목과 기존 img 경고가 남아 있음 |
| `npm run docs:curriculum` | 통과 | 화면과 같은 데이터에서 상세 수업 검토 문서 생성 |
| 홈/카테고리 카드의 프로그램 참조 34개 | 전부 등록된 프로그램과 일치 | 이번 변경 후 존재하지 않는 프로그램 카드 연결 없음 |
| 재설계 문서의 상대 링크 | 통과 | 목표·계획·수업안·미결 사항 연결 확인 |
| `git diff --check` | 통과 | 변경 파일 공백 오류 없음 |

브라우저·화면 캡처·실제 사용자 상호작용 테스트는 수행하지 않았다. 실제 상담 저장, 메일 발송, 수업안별 확정 가격 계산도 구현·검증 범위에 포함하지 않는다.

대표 사진 23개와 운영 근거 자료가 확보되지 않았으며, 상세 수업안은 3개 프로그램의 5개 제안에 적용했다. 나머지 20개 프로그램과 전용관은 재설계 계획에 따라 이어간다. 이번 검증 결과를 ‘콜로소와 디자인 완전 동일’이나 ‘홈페이지 전체 운영 준비 완료’로 해석하지 않는다.
