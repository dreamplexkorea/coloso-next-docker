# 상세페이지 전체 화면 점검

2026-09-07 · 기준: PR #1의 `ee1b92c` 이후 화면 수정안.

## 판단

다섯 템플릿의 첫 화면과 읽는 순서는 구분된다. 다만 콜로소처럼 실제 수업과 결과물이 눈에 들어오는 수준에 도달하려면 **현장 사진·결과물 예시·확인된 강사진·프로그램별 구체적인 수업 내용**이 필요하다. 빈 이미지 영역을 줄이고 반응형 오류를 고친 것만으로 상세페이지가 완성되었다고 볼 수 없다.

이번 점검에서는 화면에서 확인할 수 있는 배치·가독성·동작 문제를 수정했다. 사업 자료가 있어야 판단할 수 있는 내용은 아래 미결 항목으로 남겼다.

## 캡처 범위와 방법

- 데스크톱: 브라우저 1363 × 936px, 문서 영역 1348px. 아래 대표 프로그램 5개를 처음부터 푸터까지 캡처했다.
- 모바일: 비교 화면의 390px iframe에서 같은 5개 프로그램을 전체 길이로 캡처했다. 브라우저 스크롤바를 제외한 문서 너비는 373px였다.
- 비교 화면: 프로그램·템플릿·너비 선택, 전체 길이 보기와 기본 800px 프레임 전환을 확인했다.
- 전체 길이 캡처는 페이지 구성 확인용이며, 고정 메뉴와 하단 버튼은 높이 800px의 일반 모바일 프레임에서 별도로 확인했다.
- 실제 휴대폰, Safari, 23개 프로그램 전 페이지, 결제·상담 발송, 운영 배포 검증은 이번 범위에 포함하지 않았다. 콜로소 원본과의 픽셀 비교도 수행하지 않았다.
- 캡처에 보이는 노란 미리보기 안내와 Next.js 개발 도구 표시는 검토 환경의 표시다. 별도 ZIP에 수정 후 전체 화면 11장, 모바일 동작 화면, 수정 전 비교 자료와 한눈에 보기 이미지를 제공한다.

| 템플릿 | 대표 프로그램 | 수정 후 데스크톱 전체 크기 | 수정 후 모바일 전체 크기 |
|---|---|---|---|
| 체험 몰입형 | 마술 | 1348 × 7160 | 390 × 10555 |
| 결과물 전시형 | 바리스타 | 1348 × 6506 | 390 × 10143 |
| 프로젝트 로드맵형 | AI 리터러시, 기본 6차시 | 1348 × 10060 | 390 × 14800 |
| 학교 운영 안내형 | 3D프린터 | 1348 × 4841 | 390 × 6780 |
| 전문가 스토리형 | 건축가 | 1348 × 5564 | 390 × 8020 |

페이지 높이는 성과 점수가 아니다. 글자 확대와 정보 보존 때문에 모바일 길이가 크게 줄지 않은 페이지도 있다.

## 발견한 문제와 반영한 수정

| 우선순위 | 화면에서 확인한 문제 | 반영 내용과 확인 결과 |
|---|---|---|
| 높음 | 상세 목차가 사이트 상단 메뉴에 가림 | 상단 메뉴와 목차의 실제 높이를 측정. 데스크톱 겹침 42.5px → 0px. 수정 후 메뉴 하단 106.5px = 목차 상단 106.5px. 모바일도 103px = 103px. 목차 클릭 시 섹션은 목차 아래 약 16px에 도착 |
| 높음 | 작품형 모바일의 본문과 버튼이 오른쪽으로 넘침 | 이미지 최소 높이와 종횡비가 그리드 최소 너비를 384px로 키우던 문제 수정. 문서 373px에 scrollWidth 400px → 373px. 5개 대표 페이지에서 최종 가로 넘침 없음 |
| 높음 | AI 2·4차시를 골라도 일부 소개·유의사항은 6차시로 고정 | 첫 화면 설명을 선택한 수업안과 연결. 소개·질문·운영 문구를 2·4·6차시별 범위로 정리. 유의사항에 현재 구성 표시. 2/4/6 선택 시 100/200/300분과 ai-2/ai-4/ai-6 견적 링크 연동 확인 |
| 중간 | 사진 없는 강사진 영역에 큰 글자 한 자만 표시 | 실제 사진이 없으면 이름·역할·소개·활동 중심으로 표시. 질문은 첫 항목을 열고 나머지는 펼칠 수 있게 구성 |
| 중간 | 사진 없는 소개 영역이 제목을 반복하는 큰 색상 상자로 표시 | 해당 소개를 번호·제목·설명으로 정리하고 과한 간격 축소. 실제 이미지 주소가 있는 소개의 이미지 렌더링은 유지 |
| 중간 | 유의사항·준비물 설명이 작고 흐림 | 유의사항 본문 12px → 16px. 준비물 설명 16px. 데스크톱 분할 배치와 모바일 한 열 배치. 푸터 글자 대비와 크기 보완 |
| 중간 | 모바일의 견적·문의 버튼이 같은 주소로 이동 | 하단을 하나의 ‘견적 살펴보기’ 버튼으로 정리. 배경을 더 불투명하게 하고 하단 여백 확보. 모바일 화면에서 표시되는 고정 견적 버튼 1개 확인 |
| 중간 | 비교 화면 설명이 길어 미리보기를 늦게 만남 | 설명·간격 축소, 구성 순서 접기, 전체 길이 보기 추가. 초기 프레임 시작점 840px, 비교 화면 전체 높이 2267px → 1971px. 전체 길이 보기에서 프로그램 변경에 맞춰 프레임 축소·확대 확인 |
| 낮음 | 로고가 페이지 제목 h1과 중복, 푸터 링크에 React 중복 key | 로고를 일반 컨테이너로 변경. 제목 h1 1개 확인. 푸터 key에 주소와 라벨을 함께 사용 |
| 낮음 | 모바일 한글 제목이 단어 중간에서 줄바꿈 | 제목과 소개의 한글 단어 묶음을 유지. 좁은 화면에서 넘치지 않도록 긴 문자열 줄바꿈 허용 |

## 검증 결과

- 프로덕션 빌드·TypeScript·페이지 생성 통과.
- 템플릿 7개, 커리큘럼 5개, 최근 본 프로그램 5개: 총 17개 테스트 통과.
- lint 오류 0개, 기존 경고 4개. `git diff --check` 통과.
- 같은 AI 프로그램에서 다섯 템플릿으로 전환되는 실제 iframe 주소와 렌더링 구성을 확인.
- 모바일 2차시 선택, 질문 펼치기, 목차 이동, 선택된 견적 주소와 하단 단일 버튼 확인. 데스크톱 2·4·6차시 선택 확인.
- 이미지 누락 시 결과물 문장으로 대체되는 동작 확인. 이미지 파일 누락 자체는 미해결이다.
- 로고 SVG의 Next Image 크기 경고는 개발 콘솔에 남아 있다. 화면 비율 손상은 관찰되지 않았다. 브라우저 확장 자체의 오류는 앱 오류와 분리했다.

기본 브랜치 병합과 운영 배포는 수행하지 않았다.
