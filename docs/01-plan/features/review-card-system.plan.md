## 1. 문제 정의

### 현재 상태
- `Reviews.tsx`의 후기 카드가 **직사각형으로 비율이 깨져** 있음
- 포토 리뷰 이미지 `h-[200px]` 고정값 → 카드 간 높이 불균일
- 포토 있는 카드 vs 없는 카드 높이 차이가 커서 3열 그리드 정렬 불량
- 다른 과목(강의)에서도 재사용할 시스템적 구조가 부재
- 후기 4개 표시 시 3열 그리드에서 마지막 1개가 어색하게 배치됨

### 현재 Review 타입
```typescript
interface Review {
  id: string;
  rating: number;
  title: string;
  content: string;
  authorName: string;
  authorGrade: string;
  authorAvatarSrc?: string;
  photoSrc?: string;
}
```

### 현재 컴포넌트 구조
```
Reviews.tsx (단일 파일)
├── StarIcon (별점 SVG)
├── ReviewCard (카드 1개)
└── Reviews (섹션 전체: 헤더 + 3열 고정 그리드)
```

## 3. 변경 범위

### 3.1 타입 수정 (`types.ts`)
- `Review` 인터페이스는 현재 충분 → **변경 없음**

### 3.2 데이터 수정 (`courseDetail.ts`)
- 기존 3개 → **4개**로 후기 1개 추가
- 포토 있는 카드 / 없는 카드 혼합 유지

### 3.3 컴포넌트 리디자인

#### A. ReviewCard — 카드 비율 정상화

**핵심 문제 해결 — 카드 높이 균일화:**

| 현재 | 변경 |
|------|------|
| 포토: `h-[200px]` 고정 → 높이 들쭉날쭉 | 포토: `aspect-[4/3]` 비율 고정 |
| 콘텐츠 길이에 따라 불균일 | `line-clamp` 처리로 균일화 |
| 포토 없는 카드에 빈 공간 없음 | accent 배경 + 큰 따옴표 아이콘 placeholder |

**카드 레이아웃:**
```
┌──────────────────────┐
│                      │
│   포토 이미지         │  ← aspect-[4/3] 고정 비율
│   (또는 인용 아이콘)   │     포토 없으면 브랜드컬러 배경 + " 아이콘
│                      │
├──────────────────────┤
│ ★★★★★              │  ← 별점
│                      │
│ "후기 제목"           │  ← font-bold, line-clamp-2
│                      │
│ 후기 내용 텍스트...    │  ← line-clamp-3 (최대 3줄)
│                      │
│ ┌──┐ 김*민 학생       │  ← 아바타 + 이름 + 학년
│ └──┘ 초등학교 6학년    │
└──────────────────────┘
```

**호버 효과:**
- `hover:-translate-y-1 hover:shadow-lg transition-all duration-300`

#### B. 캐러셀 슬라이드 시스템 (신규)

**왜 캐러셀인가:**
- 후기 4개를 3열 그리드에 넣으면 마지막 1개가 어색하게 혼자 남음
- 과목마다 후기 수가 다를 수 있음 (3개, 4개, 6개, 10개...)
- 캐러셀로 3장씩 보여주고 좌우로 넘기면 어떤 개수든 자연스러움

**슬라이드 동작:**
```
데스크톱 (md+): 한 번에 3장 표시, 좌우 화살표로 이동
┌────────────────────────────────────────────┐
│  ◀  │ Card 1 │ Card 2 │ Card 3 │  ▶      │
└────────────────────────────────────────────┘
       ← 화살표 클릭 시 1장씩 슬라이드 →

모바일: 한 번에 1장 표시, 스와이프 또는 화살표로 이동
┌──────────────────┐
│  ◀  │ Card 1 │ ▶ │
└──────────────────┘
       ← 스와이프 →

dot indicator: ● ○ ○ ○ (현재 위치 표시)
```

**구현 방식 — CSS scroll-snap (라이브러리 없이):**
- `overflow-x: auto` + `scroll-snap-type: x mandatory`
- 각 카드 `scroll-snap-align: start` + `flex-shrink-0`
- 카드 너비: 모바일 `100%`, sm `50%`, md `33.333%`
- 좌우 화살표 버튼: 클릭 시 `scrollBy()` 호출
- dot indicator: `IntersectionObserver` 또는 `scroll` 이벤트로 현재 위치 추적
- **"use client"** 필요 → `ReviewCarousel` 클라이언트 컴포넌트로 분리

**3개 이하일 때:**
- 데스크톱에서 3개 이하면 화살표/dot 숨김 (그리드처럼 동작)
- 모바일에서는 항상 스와이프 가능

### 3.4 캐릭터 아바타 시스템 (v3 추가)

**요구사항**: 모든 후기 작성자의 얼굴을 실사 사진 대신 **귀여운 캐릭터 아바타**로 표시.
지루하지 않게 각 리뷰어마다 다른 캐릭터 디자인.

**구현 방식 — 인라인 SVG 캐릭터:**
- `Review` 타입에 `characterId` 필드 추가 (1~N 중 하나)
- `CharacterAvatar` 컴포넌트: characterId별 다른 머리색/표정/액세서리 SVG 렌더
- `authorAvatarSrc` (Unsplash 실사 URL) 제거 → `characterId`로 대체
- 외부 의존 없음, 로딩 빠름, 어떤 과목에서든 재사용 가능

**캐릭터 4종:**
```
1번: 분홍 단발 + 웃는 표정 (활발한 학생)
2번: 파란 안경 + 차분한 표정 (진지한 학생)
3번: 초록 모자 + 환한 미소 (모험적인 학생)
4번: 보라 머리띠 + 똑똑한 표정 (창의적인 학생)
```

**카드 내 아바타 위치**: 기존과 동일 (하단 작성자 영역 40x40 원형)

### 3.5 섹션 헤더 유지
- 현재 `BEST REVIEWS` eyebrow + 평균 별점 헤더 → **유지**

### 3.5 파일 구조 변경

```
변경 전:
  Reviews.tsx (단일 파일, 서버 컴포넌트)

변경 후:
  Reviews.tsx          (서버 컴포넌트 — 섹션 헤더 + ReviewCarousel 호출)
  ReviewCarousel.tsx   (클라이언트 컴포넌트 — 스크롤 캐러셀 + 화살표 + dot)
```

## 4. 시스템 설계 원칙

### 재사용성
- `Reviews` 컴포넌트는 `reviews: Review[]` prop만 받으면 어떤 페이지에서든 동작
- 카드 개수에 따라 캐러셀 자동 활성화 (4개+ → 슬라이드, 3개 이하 → 정적 표시)
- CSS scroll-snap 기반 → 외부 라이브러리 의존 없음

### 일관성
- 포토 유/무 관계없이 카드 상단 영역 동일 높이 (`aspect-[4/3]`)
- `line-clamp`으로 텍스트 줄 수 제한 → 카드 간 높이 균일
- CSS 변수 체계 활용

## 6. 리스크

| 리스크 | 대응 |
|--------|------|
| scroll-snap이 일부 구형 브라우저에서 미지원 | 2024+ 브라우저 95%+ 지원, graceful fallback (일반 스크롤) |
| 모바일 스와이프 감도 이슈 | `-webkit-overflow-scrolling: touch` + `scroll-behavior: smooth` |
| line-clamp 시 중요 내용 잘림 | 3줄이면 충분, 필요 시 "더보기" 추가 |
| 카드 수 1~2개일 때 빈 공간 | 카드가 뷰포트보다 적으면 중앙 정렬, 화살표/dot 숨김 |
