## 1. 사이트 전역 디자인 DNA

| 속성 | 클로소 관측값 | 시사점 |
|------|---------------|--------|
| **톤** | 화이트/라이트 기본, 비비드 썸네일 대비 | 콘텐츠(썸네일/영상)가 색을 책임지고 UI는 중립 |
| **타이포** | 모던 산세리프, 헤더 볼드 / 본문 라이트~레귤러 | 강한 위계 대비 |

| **카드** | 썸네일(상태배지 좌상단) + 강사 + 제목 + 메타, 호버 반응 | 정보 밀도 + 클릭 유도 |
| **CTA** | 솔리드 고대비 버튼 + 텍스트 보조링크, 듀얼 구조 | 고/저 관여 동시 흡수 |
| **결제 신호** | "12개월 무이자", "평생시청" 반복 | 마찰 제거를 디자인 요소로 상시 노출 |

## 2. 페이지 아키타입

### 2.1 홈 (Home)
**구조(상→하)**: 스티키 헤더(로고·프로모바·카테고리·보조내비) → 풀폭 **프로모 히어로 캐러셀**("3개 가격에 3개 더!", "1만 원부터") → 카테고리 퀵링크 → **장르별 강의 캐러셀 다수**(베스트/신규/얼리버드 등) → 와이드 프로모 배너 → 푸터(멀티리전·법적·사업자).
- **왜**: 첫 화면=프로모 후킹, 이후 캐러셀로 폭넓은 카탈로그를 스크롤 탐색에 최적화.
- **어디에**: 카탈로그형 홈(코스·프로그램·상품 다수).
- **본 레포 매핑**: `src/app/page.tsx`(HeroBanner→QuickLinks→CourseCarousel→WideBanner→PersonalizedSection) — 이미 동형.

### 2.2 카테고리 / 상위 메뉴
**구조**: 10개 상위 카테고리(드로잉·영상/애니·게임제작·베이킹/쿠킹·디자인·AI/테크·창작/라이프·헤어/뷰티·부업/재테크·창업/커리어) 드롭다운 + 그리드 카드 목록.
- **본 레포 매핑**: `src/lib/data/navigation.ts`, `CategoryCarousels.tsx`.

### 2.3 ★ 상품 상세페이지 — 13단 아키타입 (클로소 디자인의 핵심)
모든 장르(일러스트~헤어~게임~AI)에서 **동일 골격**이 반복됨. 이게 "클로소 디자이너처럼"의 실체.

| # | 섹션 | 구조/디자인 | 왜 효과적 |
|---|------|-------------|-----------|
| 1 | **히어로** | 풀폭 비주얼 + eyebrow(감성) + 성과형 headline(대형 볼드) + 강사 정체성 + 증빙 1줄 + 가격/얼리버드 CTA | 3초 안에 욕망·성과·신뢰·행동 전부 제시 |
| 2 | **문제/페인** | 비주얼 그리드로 타깃의 실패 장면 | 공감→자기관련성 |
| 3 | **가치제안** | 아이콘 3카드(산출물/혜택) | 받는 것 명료화 |
| 4 | **사회적 증거** | 지표 + 동료/권위 추천 + 비포-애프터 | 신뢰 이전 |
| 5 | **클래스 정보 박스** | 회차·난이도·언어·평생시청·자료·할부 | 사양 한눈에, 마찰 제거 |
| 6 | **커리큘럼** | 다섹션 점층(기초→고급), 기술용어+성과 언어 | 완주 가능성·전문성 동시 신호 |
| 7 | **강사 프로필** | 경력·실명 실적(브랜드/작품)·출간·현직 | 권위 |
| 8 | **Q&A 인터뷰** | 4문답, 반론 선제 처리 | 구매 장벽 제거 |
| 9 | **예시 갤러리** | 영상/이미지 비포-애프터 | 방법론 시각 증명 |
| 10 | **시리즈/연계** | N부작 중 위치 표시 | 업셀·시리즈 커밋 |
| 11 | **유의/환불** | 단계별 환불 스케줄·기기 제한 | 투명성=신뢰 + 캐주얼 구매 허들 |
| 12 | **가격/결제** | 앵커가 + 무이자 할부 + 평생 | 가격 마찰 최소화 |
| 13 | **듀얼 CTA** | "얼리버드 구매하기" + "수강예약"/"크리에이터 페이지" | 고·저 관여 동시 |

- **본 레포 매핑**: `src/app/products/[slug]/page.tsx` 렌더 순서(ProductHero→TabNavigation→ClassIntro→Curriculum→CreatorProfile→Reviews→NoticeSection→RelatedCourses→StickyBottomSummary)가 이 13단과 **거의 1:1**. `CourseDetail` 타입에 필드 존재(`heroProofStats`·`curriculum`·`targetAudience`·`expectedOutcomes`·`reviews`·`notice`).

### 2.4 무료 퍼널 페이지 (`[0원]` 스낵)
**구조**: 강한 후킹 헤드라인("어디서도 배울 수 없는…대공개!") → 가치 입증 → **리드 캡처(계정+이메일)** → 인접 유료 추천.
- **왜**: 무료로 신뢰·리드 확보 후 전환.
- **본 레포 매핑(가능)**: "무료 진로 자료/샘플 차시" → `/ai-quote` 상담 리드로 연결.

## 3. 히어로 변형 카탈로그

| 변형 | 특징 | 사용처 |
|------|------|--------|
| **Overlay**(중앙 텍스트 카드) | 풀블리드 이미지 + 중앙 대형 타이틀 | 브랜딩·프로모 |
| **Split**(이미지+텍스트 비대칭) | 60/40 분할, 글래스 카드 | 정보형 |
| **Product Hero**(상세) | 비주얼 + 성과 헤드라인 + 강사 + **증빙지표 3칸 + 하이라이트 4칸** | 상세페이지 |
- **본 레포 매핑**: `HeroBannerClient.tsx`(overlay/split), `ProductHero.tsx`(증빙 3칸·하이라이트 4칸, `heroTheme` cinematic-dark/mid).

## 4. 반복 컴포넌트 해부

- **상태 배지**: 썸네일 좌상단 `absolute left-[8px] top-[8px]`, 카피 `BEST/HOT/날짜 오픈`. → `CourseCard.tsx` + `Badge.tsx`.
- **증빙지표 스트립**: label(작게·대문자) + value(크게·볼드) 3칸. → `ProductHero` proof stats.
- **하이라이트 4칸**: 대상·차시·방식·시간. → `programHighlights`.
- **정보 박스**: 회차/난이도/언어/자료/할부 리스트. → `CourseMeta` + `StickyBottomSummary`.
- **커리큘럼 아코디언**: 챕터→레슨, learningPoint. → `CurriculumChapter`.
- **후기 캐러셀**: 별점·제목·내용·작성자(학년). → `Review` + Reviews.
- **듀얼 CTA 바**: 솔리드 1차 + 보조 링크. → `StickyBottomSummary`.

## 5. 본 레포 ↔ 클로소 갭 (디자인 관점)

| 항목 | 클로소 | 본 레포 | 판정 |
|------|--------|---------|------|
| 상세 13단 골격 | 전 장르 동형 | `[slug]/page.tsx` 거의 1:1 | ✅ 정렬됨 |
| 히어로 톤 | 라이트 기본 | 다크 `--hero-*`/`--coloso-*` | 🟡 다크는 "몰입 섹션 전용"으로 스코프(스펙 §1-B) |
| 증빙지표 | 누적 수강생/뷰 | 운영학교/참여학생/만족도(이미 구현) | ✅ |
| 듀얼 CTA | 구매+예약 | StickyBottom 메타 위주 | 🟡 "상담 신청 + 자세히" 듀얼 CTA 보강 여지 |
| 배지 카피 | BEST/날짜오픈 | 자체 카피 | 🟡 상태/오픈일 패턴 추가 검토 |
| 무료 퍼널 | 스낵 강의 | 없음 | 🟡 선택적 리드 퍼널 |

## 6. 재캡처/갱신 절차 (포터블)
새 참고 사이트를 분석할 때(클로소든 타 사이트든):
1. `sitemap.xml`로 URL 인벤토리 → 페이지 타입 분류.
2. 타입별 대표 ~2개씩 WebFetch, **섹션 순서 + 디자인 + 카피**를 동시 추출.
3. 본 문서 §2 표 형식으로 아키타입화(구조→왜→어디→매핑).
4. 갭 표(§5) 갱신 → 스펙(`coloso-design-system.md`)·플레이북에 반영.
> 이 절차는 `coloso-design-analyst` 에이전트의 표준 작업 정의이기도 함.
