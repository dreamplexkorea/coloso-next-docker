# Coloso 라이브 사이트 레퍼런스 (Ground Truth)

> 출처: `https://coloso.co.kr` (캡처일 2026-06-01, WebFetch). 디자인 에이전트가 "실제 클로소"를 판단할 때 참조하는 정답지. 본 레포 구현과의 갭을 표로 정리한다.

## 1. 전체 인상 (Look & Feel)

- **밝은 톤이 기본.** 화이트/연한 뉴트럴 배경 위에 비비드한 강의 썸네일이 올라가는 구조. (과거 인상과 달리 현재 클로소는 "다크 시네마틱"이 아니다.)
- 분위기: **밝고 · 에너제틱 · 프로페셔널.** 미니멀한 레이아웃 + 화려한 크리에이티브 이미지의 대비.
- 타이포: 깔끔한 모던 산세리프. 헤더는 볼드, 본문은 라이트~레귤러.
- 텍스트: 짙은 그레이/블랙이 본문 기본색.

## 2. 헤더 / 내비게이션

좌→우 순서:
1. Coloso 로고(홈 링크)
2. 프로모션 배너 링크(3+3 이벤트, 클래스 딜, 체험 프로그램 등)
3. 카테고리 메뉴(확장형 드롭다운)
4. 보조 내비: 홈 · 이벤트 · 포트폴리오 · 교육 바우처 · 베스트 클래스 · 웰컴 혜택 · 이벤트 목록

스티키 헤더, 접근성 지원.

### 상위 카테고리 (10개)
드로잉 · 영상/애니메이션 · 게임제작 · 베이킹/쿠킹 · 디자인 · AI/테크 · 창작/라이프 · 헤어/뷰티 · 부업/재테크 · 창업/커리어

## 3. 히어로 / 프로모션 배너

- 풀폭 프로모션 배너 **캐러셀**.
- 카피 톤(한국어, 강한 후킹):
  - "3개 가격에 3개 더!"
  - "1만 원부터, 초저가 보장"
  - "0원부터 천원 강의까지"
- 굵은 타이포 오버레이 + 강의 이미지.

## 4. 강의 카드 해부

- 사각 썸네일 이미지 + 하단 메타데이터
- 강사명 · 강의 제목이 이미지 아래
- 상태 배지가 **좌상단**에 위치
- 배지 카피 스타일: `BEST` · `HOT` · `08.06 오픈`(오픈일) · `수강가능` · 카테고리 태그
- 호버 반응형

## 5. 푸터

- 법적: 이용약관 · 개인정보처리방침 · 환불정책
- 고객지원: 평일 10:00–18:00

| 푸터 | 멀티리전·법적·고객지원·사업자 | `src/lib/data/footer.ts` | 🟡 데이터 대조 필요 |
| 카피 톤 | 강한 후킹("3개 가격에 3개 더!") | 데이터 파일 카피 | 🟡 보강(프로모 카피 톤 맞추기) |

### 핵심 결론
1. **라이트 테마가 정답.** 레포 라이트 토큰 유지 = 올바른 방향.
2. **다크 `--coloso-*` / `--hero-*` 토큰은 충돌이 아니라 "히어로/몰입 섹션 전용 서브시스템"** 으로 스코프를 한정한다. 글로벌 캐논은 라이트.
3. 보강 우선순위: ① 히어로 톤(다크→라이트 검토 or 명시적 스코프), ② 배지 카피/상태 패턴, ③ 프로모 카피 톤, ④ 강사명 노출.
