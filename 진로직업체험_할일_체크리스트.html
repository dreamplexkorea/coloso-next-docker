📄 상세페이지 & 사진·후기 콘텐츠5가지

01
진로직업체험 상세페이지 — 사진 작업 + 문서 작업
높음
핵심 할 일
  • 체험 현장 사진 갤러리 섹션 추가 (3~6장 그리드, 클릭 시 확대)
  • 프로그램 소개 문서(커리큘럼·진행 순서·준비물)를 카드/아코디언으로 정리
  • 학교·기관 배포용 PDF 안내서 다운로드 버튼
구현 아이디어
기존 카드 컴포넌트를 재활용해 사진 갤러리 ↔ 문서 섹션을 번갈아 배치하면 통일감 유지. 사진은 최적화 로딩.
⚠️ 확인 필요 — 현장 사진 실물 보유 여부, 최신 커리큘럼 문서 파일 위치
02
학생 후기 넣기 — 초등학교 / 중학교 나눠서
높음
핵심 할 일
  • 후기 섹션을 '초등 / 중등' 탭 또는 좌우 분리로 구성
  • 후기 카드: 학년·이름(익명 옵션)·한 줄 소감·별점/아이콘
  • 후기 데이터를 별도 파일로 분리해 나중에 추가·수정 쉽게
구현 아이디어
후기를 데이터 목록으로 만들어 두면, 후기가 늘어도 내용만 추가하면 자동으로 카드가 붙음. 탭 전환은 간단하게.
⚠️ 확인 필요 — 실제 후기 원문, 이름·얼굴 공개 범위(실명/익명/사진 동의)
05
드림하이 초등관 상세페이지 — 학년별 추천
중간
핵심 할 일
  • 저학년(1~2)/중학년(3~4)/고학년(5~6) 3구간 추천 카드·표
  • 구간별 추천 이유·난이도·추천 활동 1~2줄
  • 학년 클릭 시 관련 프로그램으로 연결(링크 있으면)
구현 아이디어
학년 구간을 탭 또는 3열 카드 + 색상 구분으로 두면 학부모가 자기 아이 학년을 바로 찾음.
⚠️ 확인 필요 — 학년별 어떤 프로그램을 추천할지 매칭 기준(교육 기준)
12
드림하이 초등관 — '어떻게 진행하면 좋을지' 안내 영상
중간
핵심 할 일
  • 상세페이지 소개 섹션에 안내 영상 임베드 영역
  • 영상 아래 핵심 포인트 3~4개 텍스트 요약(영상 안 보는 사람 대비)
  • 모바일에서도 안 깨지는 반응형 16:9 처리
구현 아이디어
영상은 유튜브 미등록으로 올려 임베드하면 사이트 부담 없음. 썸네일 클릭 시 재생되게 하면 초기 로딩도 가벼움.
⚠️ 확인 필요 — 안내 영상 실물 유무(없으면 촬영·편집 필요), 호스팅 방식
13
진로체험 상세페이지 — 대표 사진 어떻게 구할지 정하기
높음
핵심 할 일 — 3가지 옵션 중 선택
  • ① 직접 촬영 — 실제 현장 촬영, 신뢰도 최고 / 단 초상권 동의서 필요
  • ② 무료 스톡 — Unsplash·Pexels 등 상업적 무료 이미지, 즉시 사용 / 단 '우리 현장' 느낌 약함
  • ③ AI 생성 — 분위기 컷 생성, 초상권 부담 없음 / 단 진짜 사진만큼 신뢰는 낮음
  • 고른 방식으로 대표 사진 1~2장 확보 → 히어로 영역 배치(텍스트 겹치면 어두운 오버레이)
구현 아이디어
단기엔 무료 스톡/AI로 먼저 채워 페이지 완성 → 실촬영본 확보되면 교체하는 2단계 전략 추천.
⚠️ 확인 필요 — 실제 체험 촬영본 보유 여부, 학생 얼굴 노출 동의서 가능 여부

🎬 영상 & AI 클래스관4가지 · 순서 추천: 6 → 11 → 4 · 14

04
각 커리큘럼에 동영상 홍보 넣기
중간
핵심 할 일
  • 커리큘럼 데이터에 '홍보 영상 주소' 항목 추가하고 값 채우기
  • 상세 페이지 소개 영역에 영상 플레이어 배치
  • 영상 없는 커리큘럼은 기존 이미지 그대로 나오게(영상 있을 때만 노출)
구현 아이디어
30~60초 짧은 클립을 유튜브/Vimeo에 올려 링크만 연결. HOT/인기 커리큘럼부터 채우고 나머지는 순차 추가.
⚠️ 확인 필요 — 유튜브(무료·광고 붙음) vs Vimeo(유료·깔끔) 중 선택, 첫 배치 우선 커리큘럼 목록
06
AI 클래스관 — 로드맵 + 단계 클릭 시 상세 커리큘럼
높음
핵심 할 일
  • '입문 → 기초 → 심화 → 실전' 같은 단계형 로드맵을 시각적으로 배치
  • 로드맵 단계 데이터(단계명·설명·연결 커리큘럼) 정리
  • 단계 클릭 시 상세 커리큘럼이 아코디언으로 펼쳐지고 → 상품 페이지로 연결
구현 아이디어
세로 타임라인 + 아코디언이 모바일에 안정적. 단계별 색·아이콘을 달리해 '내가 지금 어느 수준인지' 직관적으로.
⚠️ 확인 필요 — 몇 단계로/어떤 이름으로 나눌지, 각 단계에 어떤 커리큘럼을 넣을지 매핑표
11
AI 클래스관 — 관 전체 소개 영상
중간
핵심 할 일
  • 페이지 최상단(로드맵 위)에 관 전체 소개 대표 영상 1개 배치
  • 진입 시 히어로 영역에 영상이 배경/카드로 바로 보이게
  • '소개 영상 → 로드맵 → 단계별 상세' 세로 흐름으로 정리
구현 아이디어
1~2분 요약 영상 1개면 충분. 배경은 소리 끈 자동재생 루프, 가운데 재생 버튼 누르면 소리 있는 전체 영상.
⚠️ 확인 필요 — 새로 제작할지 / 14번 영상 중 하나를 대표로 쓸지, 완성 전 임시 이미지로 채울지
14
AI 클래스관 — 각 홍보 영상 제작(우리만의 사이트 소개)
낮음 · 직접 제작 대기
핵심 할 일
  • 소개할 '우리만의 사이트' 목록 확정 (사이트명·한 줄 소개·보여줄 화면 순서)
  • 사이트마다 홍보 영상 1개씩 촬영·편집 → 업로드 후 로드맵/카드에 연결
  • 썸네일·제목 형식 통일해 시리즈처럼 보이게
구현 아이디어
사이트별 30~45초 화면녹화 + 자막이면 촬영 없이 빠르게 양산. 공통 인트로/아웃트로 5초 템플릿으로 통일감 확보. 세로형(9:16)이면 쇼츠 재활용까지.
⚠️ 확인 필요 — '우리만의 사이트들' 구체 목록(필수), 완성 예상 시점 · 영상 없는 동안 '준비 중' 표시 여부

⚙️ 기능 · 브랜딩 · 커뮤니티6가지

03
견적요청 — 요청 즉시 예상 견적 자동 계산 + 쉬운 UI/UX
높음
핵심 할 일
  • 입력 폼: 인원수 · 학년(초/중/고) · 희망 프로그램(다중 선택) · 날짜 · 장소(시설/학교 방문)
  • 선택값에 따라 예상 금액이 실시간으로 바뀌는 자동 계산(단가표 기반)
  • '이 내용으로 정식 견적 요청' 버튼 → 담당자 알림 + 내역 저장
  • 견적서 PDF 다운로드/요약 카드 제공
구현 아이디어
왼쪽 입력 폼 · 오른쪽에 실시간으로 숫자가 바뀌는 '예상 금액' 고정 카드. 버튼·슬라이더만 눌러도 금액이 보이게.
⚠️ 확인 필요 — 프로그램별 1인 단가표, 인원/학년별 할인 기준, 최소 인원, 부가세 포함 여부 (이 숫자가 있어야 자동 계산 가능)
08
재미있는 체험모험ZIP — 드론·범죄과학수사를 영화처럼
높음
핵심 할 일
  • 대표 체험(드론·CSI 등)마다 개별 카드/페이지 — 예고편 느낌 문구 + 현장 사진/영상
  • CSI는 '사건 현장 → 단서 수집 → 범인 검거', 드론은 '조종 → 미션 비행' 스토리 흐름
  • 목록을 넷플릭스처럼 큰 썸네일 + 호버 시 영상/움직임 갤러리로
  • 각 카드에서 바로 견적요청으로 연결(프로그램 미리 선택된 상태)
구현 아이디어
어두운 배경 + 큰 이미지 + 영화 포스터 톤 카피로 "체험이 아니라 하나의 사건에 참여한다"는 느낌을.
⚠️ 확인 필요 — 각 체험 실제 사진·영상 자료, 운영 중인 체험 전체 목록, 대표로 강조할 3~4개
09
메인페이지 — '스튜디오' 컨셉
중간
핵심 할 일
  • 첫 화면을 촬영 스튜디오/제작소 느낌으로 (큰 영상·이미지 + 콘셉트 카피)
  • 각 '관'을 스튜디오의 세트장/공간처럼 나눠 보여주는 섹션
  • 스크롤에 따라 등장하는 애니메이션·전환으로 영상 편집 같은 흐름
  • 색·폰트·여백을 스튜디오 콘셉트로 전체 통일
구현 아이디어
다크 톤 + 필름/카메라·조명 모티프를 은은하게. 각 관을 '촬영장 문을 여는' 느낌의 카드로 진입.
⚠️ 확인 필요 — 스튜디오를 어디까지 밀지(은유만 vs 카메라·필름 적극), 브랜드 색·로고·폰트 가이드
10
드림팀 소개에 '드림플렉스' 소개 넣기
중간
핵심 할 일
  • 드림팀 소개 안에 '드림플렉스가 어떤 회사인지'(정체성·미션·하는 일) 섹션 추가
  • 드림팀 ↔ 드림플렉스 관계를 한눈에(상위 브랜드가 누구인지) 정리
  • 연혁·주요 실적·함께한 학교 수 등 신뢰 정보 배치
구현 아이디어
상단에 "드림플렉스는 이런 회사입니다" 요약 블록 → 그 아래 드림팀(구성원·팀 소개)으로 자연스럽게 연결.
⚠️ 확인 필요 — 드림플렉스와 드림팀의 정확한 관계, 회사 소개 문구·연혁·실적 자료
07
게시판 만들기 + 홍보 내용 노출
중간
핵심 할 일
  • 글 목록/상세/글쓰기가 있는 기본 게시판(제목·작성일·조회수·사진 첨부)
  • 관리자만 글쓰기, 방문자는 보기 위주로 권한 분리
  • 상단에 '공지/홍보' 고정 영역 — 이벤트·모집·프로그램 소개가 항상 위에
  • 새 글 작성 시 메인 '새 소식'에 자동 미리보기
구현 아이디어
홍보/공지 글에 태그를 달아 항상 상단 고정 + 색상 강조 카드로. 15번 학교 블로그와 구조를 공유하면 관리 편함.
⚠️ 확인 필요 — 방문자 댓글/문의를 넣을지(스팸 관리 부담), 첫 홍보 글 초안
15
학교 진행 블로그 — 진행한 학교가 계속 쌓이게
중간
핵심 할 일
  • 'OO초 드론 체험 진행' 같은 기록을 한 건씩 쌓는 목록형 페이지(학교명·날짜·프로그램·사진)
  • 최신순 정렬 + 학교급/프로그램/지역 필터·검색
  • 글 상세에 현장 사진 여러 장 + 짧은 후기
  • 상단에 '지금까지 함께한 학교 OO곳' 누적 카운터
구현 아이디어
7번 게시판과 같은 구조를 재사용하되 '학교 진행' 전용 분류로 운영하면 관리 부담이 줄어듦.
⚠️ 확인 필요 — 지금까지 진행한 학교 리스트·현장 사진, 학교명·사진 공개 동의 여부
높음 중간 낮음 확인 필요 = 사장님 자료·결정 대기
